How it works

Highlight, ask, and keep the thread.

The chat stays attached to the passage you selected. Follow-up questions continue the same conversation.

1

Highlight

Select a passage on any page. A small Ask button appears beside it. Click it, or press Alt+Shift+D.

2

Ask

Choose a provider and type a question. The passage is sent as context, and the reply streams in as formatted text.

3

Keep the thread

Ask a follow-up in the same pop-up. Later, reopen the conversation from history—pages, highlights, and chats, stored in this browser.

Privacy

It runs on your computer.

There is no Double Click AI server for your highlights or chats. The helper is a local program that Chrome starts itself.

A local helper

Chrome launches the helper through native messaging. It speaks only to this extension and does not open a listening port.

What leaves the machine

Only the highlighted passage, the page title and address, and the question you type go to the provider you pick, through its official CLI.

History stays here

Pages, highlights, and conversations are stored in this browser, on this computer. You can search them, reopen one, or delete them.

Open source

The source is public.

Double Click AI is open source. You can read how the helper launches each CLI, how a conversation is resumed, and how API-key environment variables are stripped. Issues and changes happen in the repository.

View on GitHub

The repository is github.com/lonnylot/double-click. You can also load the extension unpacked from a local clone and register the helper with node install.js.

Install

Add the extension, then register the helper.

Install from the repository for now. A small local helper has to be registered once so Chrome can start it.

  1. 1

    Add the extension

    Follow the install instructions on GitHub and load Double Click AI unpacked from the extension folder.

  2. 2

    Register the helper

    From the project folder, run node install.js. The same step will be available as an npx command when the package is published. Run the installer again if you move the repo or upgrade Node.

  3. 3

    Sign in to a CLI

    Sign in to whichever tool you want to use, in a terminal—for example codex login or grok login. Then highlight text on a page and click Ask.

FAQ

Questions that come up first.

Do I need an API key?

No. Double Click AI starts the official CLI you are already signed into. The helper removes API-key environment variables so a tool does not silently switch to metered billing.

What does the helper do?

It is a small local program that Chrome starts through native messaging. It talks only to this extension and does not open a listening port. Each turn runs in an empty temporary folder.

Why is Claude off by default?

Anthropic’s terms do not allow third-party products to route requests through Claude plan credentials. Double Click AI only starts the Claude Code program already installed on your computer and never reads your login files. Turn it on only if you accept that arrangement. The switch is in the chat and again under Providers in history.

Where is conversation history stored?

In this browser, on this computer. Double Click AI does not host your highlights or chats.

Can I install it from the repository?

Yes. Load the unpacked extension from the extension folder, then run node install.js. The source is at github.com/lonnylot/double-click.

What is the keyboard shortcut?

Alt+Shift+D, after you have selected text.
