Privacy policy

What Double Click AI does with a highlight.

Effective November 14, 2026. Operated by LARE, LLC.

Double Click AI is a Chrome extension and a local helper. This policy covers the extension, the helper, and this website. It is written so you can see what leaves your computer before you install.

Who operates it

LARE, LLC operates Double Click AI and this website. There is no Double Click AI account, and LARE, LLC does not run a server that receives your highlights or chats.

What is sent, and where it goes

When you highlight a passage and ask a question, Double Click AI sends that turn only to the official command-line tool for the provider you pick. The helper starts that program on your computer, using the sign-in you already have. The following go to that provider, and nowhere else:

  • the highlighted passage
  • the page title
  • the page URL
  • the question you type, and earlier messages in that same conversation when you ask a follow-up

The provider’s own terms and privacy policy then apply to what their program does with that turn. Double Click AI does not add a copy of the turn for itself. It does not ask for an API key, and the helper removes API-key environment variables so a tool does not silently switch to metered billing. The helper does not read the login files those tools keep on disk.

Claude Code stays off until you turn it on. Anthropic’s terms do not allow third-party products to route requests through Claude plan credentials. If you enable it, Double Click AI only starts the Claude Code program already installed on your computer.

What stays in the browser

Pages, highlights, and conversations are stored in this browser, on this computer, in the extension’s local database. Double Click AI does not upload that history. You can search it, reopen a thread, or delete a conversation or a whole page from the side panel.

The helper keeps a local map from a conversation to that provider’s session id, in a file under your home directory, so a follow-up can resume. That file holds the provider name and the session id. It does not hold the passage, the page, or the question. Uninstalling the helper with node install.js --uninstall removes the host registration. Deleting conversations in the extension removes them from the browser.

What the extension can see

On pages you visit, the extension can read the text you select, plus the title and URL of that page, so it can show Ask and send the turn you start. It does not send other page content. It does not read your browsing history as a list of sites. The toolbar icon opens history stored by the extension itself. A context-menu item, “Ask Double Click AI,” appears when text is selected.

Chrome permissions used for that are storage, native messaging, the side panel, and context menus. Native messaging lets Chrome start the local helper. The helper speaks only to this extension and does not open a listening port. Each turn runs in an empty temporary folder.

This website

dcai.larehq.com is a static site. It does not set cookies, does not ask you to sign in, and does not run analytics. The pages do not collect the text you read here.

Analytics

The extension, the helper, and this website do not include analytics. If analytics are added later, this policy will be updated before they run.

Selling and sharing

LARE, LLC does not sell personal information and does not share highlights or questions with anyone other than the provider CLI you choose for that turn. There is no advertising in the extension.

Children

Double Click AI is not directed at children under 13, and LARE, LLC does not knowingly collect personal information from them.
